# Repository Guidelines

All project conventions, build commands, coding standards, and contribution guidelines are maintained in **[CLAUDE.md](./CLAUDE.md)** — the single source of truth for AI coding assistants working in this repository.

Before making changes, read `CLAUDE.md` in full and follow the task-relevant developer guidelines it links to. In particular, it covers:

- Project structure and module organization
- Build, test, and development commands
- Server persistence rules, including repository-owned transaction boundaries
- Caching and distributed-data architecture
- Java and TypeScript/Angular coding conventions
- Angular signals, safe object cloning, TUM UI, and Tailwind CSS
- Server, client, Playwright, and multi-node testing guidelines
- Commit and pull request guidelines
