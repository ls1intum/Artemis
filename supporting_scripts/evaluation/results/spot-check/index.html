Spot-check packet — 5 programming + 5 quiz variants

Each page shows the requested intent, the source and variant side by side, the LLM judge's four rubric scores with justifications and verbatim excerpts, and a blank verdict field for a human reviewer. The pom.xml artifactId/name rename that appears in every programming variant is suppressed as carrying no judgement value. The selection deliberately spans the quality range: clean successes (C3-r1, C12-r1, C8-r1), middling cases (C1-r1), and defective variants (programming C2-r6 template gaming, programming C4-r4 broken expected order, quiz C1-r2 missing distractors, quiz C2-r4 mis-marked options, quiz C11-r5 duplicated question).
