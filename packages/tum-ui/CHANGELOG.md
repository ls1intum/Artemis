# Changelog

## 0.1.0

Initial release of the TUM UI Angular component library: standalone signal-based
components, native and Angular CDK interactions, reactive forms integration, a translation adapter,
and precompiled light and dark themes. Requires Angular 22.1.7 or newer within Angular 22.

The public contract consists of the package entry point, `styles.css`, and documented semantic
theme tokens. Releases follow an independent version sequence from Artemis.
