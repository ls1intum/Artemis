# Passing Score Counter

Practice traversing an array and applying a boundary rule by counting which scores pass.

Implement `ScoreCalculator.countPassing(int[] scores)`. A score passes when it is at least 50. Return the number of passing scores. For an empty array, return 0.

For example, `[45, 50, 80]` contains 2 passing scores.
