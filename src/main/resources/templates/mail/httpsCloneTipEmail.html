Dear User,

You just used your Artemis account password to access the repository of an exercise.

Your Artemis administrators plan to stop accepting passwords for Git on a date.

How to switch your existing local repository

  1. Open the exercise in Artemis, click the Code button, choose Token and copy the address. Open the exercise in Artemis
  2. In your local repository, run this command with the copied address: 
    git remote set-url origin <copied address>
  3. If your computer saved your password, remove that entry.

Prefer SSH? Add your public key once and clone with the SSH address. Configure SSH Keys in Artemis
