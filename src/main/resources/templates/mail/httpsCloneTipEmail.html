Dear User,

We noticed that you recently accessed your exercise code using your main Artemis account password. Doing so can pose a security risk and requires entering your credentials repeatedly. We recommend using one of the following safer options instead:

  • Token (Recommended for beginners): A token is a secure, temporary password generated specifically for your exercise. To use it, open the exercise, click the </> Code button, ensure Token is selected, and copy the link. It already contains your exercise token, so you don't need to enter your personal account password.
  • SSH Key (For advanced users): SSH connects your computer using a secure digital key instead of passwords. If you are familiar with SSH, you can add your public key once in Account Settings → SSH to download and upload code without entering passwords each time.
