System notifications allow administrators to inform all users about important events such as planned maintenance windows. Notifications appear as banners in the Artemis UI for all connected users.

Each banner uses a single line, with smaller text on narrow screens. Long messages end with an ellipsis. Hover over the message or focus it with the keyboard for a preview. Click or tap the message, or press Enter while it is focused, to open the full notification. Long announcements can be scrolled in this view; press Escape or click outside it to close it. Use the close button to dismiss a notification.

## Creating a System Notification

1. Navigate to **Administration > Configuration > Notifications**.
2. Click **Create a new system notification**.
3. Fill in the form:
   - **Title**: A short descriptive title (required, max 50 characters).
   - **Text**: Additional details about the notification.
   - **Type**: `INFO` or `WARNING` (determines the banner style).
   - **Notification Date**: When the banner should start appearing.
   - **Expiration Date**: When the banner should disappear (must be after the notification date).

## Emailing Instructors

When creating a new system notification, administrators can optionally send an email to all instructors of ongoing courses:

1. Check the **Email this notification to instructors** checkbox.
2. The form displays the number of instructors who will receive the email.
3. Save the notification to send the email immediately. It includes the title, message and dates when the banner is visible. For planned maintenance, include the actual maintenance window in the message.

### Who receives the email?

- All users with the **Instructor** role in an **ongoing course** (a course that has started and not yet ended).
- Users who have **not opted out** of system announcements in their user settings.
- Only activated users with an email address. Test users receive the email only if they enabled these notifications.

### Opting out

Instructors can disable system announcement emails in **User Settings > Profile > Notifications** by toggling the **System Announcements** option.

A mail that the SMTP server does not accept is kept and sent again later, and test users receive no system announcement email unless they enabled it. See [E-Mail Delivery](/admin/email-delivery).
