Courses contain [exercises](/instructor/exercises/intro), [exams](/instructor/exams/intro) and lectures.
Different roles can be attached to different sets of course participants: Instructors, Editors, Tutors and Users.
You can find a detailed listing of the different roles and their corresponding permissions [here](/admin/access-rights).

## Creating courses

Administrators can create new courses by clicking **Course Management** in the header
and then **Create new course**.

Administrators can then specify options in the creation form, Instructors can later change these values:

- **Title** – Name of the course (shown in **Course Overview**)
- **Short Name** – Unique identifier (cannot be changed later)
- **Color** – Used throughout UI including overview
- **Course Description** – Shown during registration & course header
- **Course Organizations** – Restricts course visibility based on user organization
- **Start/End** (required) – The period the course runs for. The end date drives archival and the automatic data cleanup, so it cannot be left empty.
- **Test Course** – Exercises/exams hidden from regular users
- **Semester** (required) – Groups courses in the dashboard and in the archive. Selecting a semester fills the start and end dates with that semester's period, as long as you have not set them yourself.
- **Maximum number of points** – Used for grading key calculations
- **Decimal precision for scoring**
- **Default Programming Language**
- **Customize group names** (Admin-only)
- **Enable complaints**
- **Enable more feedback requests**
- **Enable postings by students**
- **Online Course** (LTI integration, exclusive with registration)
- **Student Course Registration Enabled**

## Managing courses

After a course is created, access it via **Course Management**.

Courses are grouped by semester, test courses listed separately.

<Image src={courseOverviewImg} alt={"Course Overview"} size={ImageSize.large} />

<Image src={courseHeaderImg} alt={"Course Header"} size={ImageSize.large} />

Clicking the course header opens the management view, where **Edit** and **Delete** act on the course and the statistics and administration options are reachable.

Students, Tutors, Editors and Instructors can be added via **Course Details**.
