A team exercise is one students hand in together: one participation, one submission and one result for the whole
team. Four of the exercise types support it —
[programming](/instructor/exercises/programming-exercise),
[modeling](/instructor/exercises/modeling-exercise),
[text](/instructor/exercises/text-exercise) and
[file upload](/instructor/exercises/file-upload-exercise).

## Create a Team Exercise

When creating an exercise, you first need to select the mode **Team**. This is only available during the creation of the exercise, as it **cannot be changed later on**.
The team size can also be configured, but it is just a recommendation that can be overridden when creating the actual teams.

<Image src={setTeamMode} alt="Set Team Mode" size={ImageSize.large} caption="Set Team Mode in Exercise Creation" />

<Callout variant={CalloutVariant.danger}>

  <strong>Important:</strong> The team mode can only be set during exercise creation and cannot be changed afterward.

</Callout>

## Manage the Teams

**Teams** on the exercise's row in the course exercise list opens team management.

<Image src={manageTeams} alt="Manage Teams" size={ImageSize.large} caption="Team Management Interface" />

### Create Teams by Hand

**Create Team** opens a dialog asking for the team's name, its short name and its students. A tutor can be assigned
to the team as well, which is optional.

<Image src={createTeamDialog} alt="Create Team Dialog" size={ImageSize.medium} caption="Create Team Dialog" />

### Edit and Delete Teams

**Edit** and **Delete** on a team change or remove it.

### Export Teams

**Export Teams** writes the exercise's teams to a file that another exercise can import.

<Callout variant={CalloutVariant.info}>

  Exporting teams is useful when you want to reuse the same team structure across multiple exercises in a course.

</Callout>

### Import Teams

**Import Teams** takes teams either from such a file or straight from another exercise in the course. Either way it
asks what to do with the teams the exercise already has: replace them, or keep them and add only the new ones.

<Image src={importStrategy} alt="Import Strategy" size={ImageSize.medium} caption="Import Strategy Options" />

## Collaboration

Students on a team exercise write in a live editor that shows what their team-mates are doing, available for
[modeling](/instructor/exercises/modeling-exercise) and [text](/instructor/exercises/text-exercise) exercises.

The live editors show the status of all the team members, and allow students to simultaneously edit the same exercise:

<Image src={liveModelingEditor} alt="Live Modeling Editor" size={ImageSize.large} caption="Live Modeling Editor with Team Collaboration" />

<Callout variant={CalloutVariant.info}>

  The live editors provide real-time collaboration features, allowing team members to see each other's changes instantly.

</Callout>

## Team Overview

The same team can be shared for multiple exercises.
Viewing the page for a single team allows students, tutors and instructors to get an overview of all the exercises for that team along with their current status.
**Team** or the team's short name opens it, and students, tutors and instructors all see the same page.

<Image src={teamOverviewPage} alt="Team Overview Page" size={ImageSize.large} caption="Team Overview Page" />

## What Students See

Students on a team exercise share one participation and one result, and write together in the live editor — see
[Exercises](/student/exercises/intro) on the student pages.
