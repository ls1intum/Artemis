A file upload exercise asks each student for a file: a scanned worksheet, a PDF report, an image of a hand-drawn
diagram. Artemis stores what they hand in and shows it to you for grading; there is nothing to run and nothing to
check automatically, so every submission is assessed by hand.

Use it when the work happens outside Artemis and only the result needs collecting. When you want the work itself to
happen in Artemis, one of the other exercise types fits better — a
[text exercise](/instructor/exercises/text-exercise) for prose, a
[modeling exercise](/instructor/exercises/modeling-exercise) for diagrams.

## Create the Exercise

**Create File Upload Exercise** sits on the course's **Exercises** page in course management. The form asks for the
same things every exercise does — title, release and due dates, points, difficulty — plus one field of its own.

**File Pattern** lists the extensions a student may upload, comma separated and without the dots, for example
`png, pdf`. A submission whose extension is not on the list is refused, so the list has to cover every form the
answer may legitimately take. There is no default: an empty pattern accepts nothing.

<Image src={creationForm} alt="File upload exercise creation form with the File Pattern field filled in" size={ImageSize.large} caption="Creating a file upload exercise" />

The exercise then appears on the course's exercise list, where **Edit** reopens the form and the title opens the
exercise itself.

<Image src={exerciseInDashboard} alt="Course exercise list showing the new file upload exercise" size={ImageSize.large} caption="The exercise on the course's exercise list" />

## Assess Submissions

Assessment opens once the due date has passed. From the assessment dashboard, open the exercise's own dashboard and
start an assessment: Artemis hands you one submission at a time.

Download the file the student uploaded, read it, and record what you find as feedback with points against it. There
are no automatic results to build on, so the whole mark comes from the feedback you write.
[Structured grading instructions](/instructor/assessment-grading/assessment) are worth setting up first if several
people are marking, because they keep the criteria and the points the same across assessors.

<Image src={assessmentView} alt="Assessment view of a file upload submission with the feedback editor" size={ImageSize.large} caption="Assessing a file upload submission" />

## What Students See

Students choose a file, submit it, and can download it again afterwards to confirm what arrived —
see [File Upload Exercise](/student/exercises/file-upload-exercise) on the student pages.
