# Connect a TUM.Live course

Open **Course Management → TUM.Live**. Only course instructors can manage this connection.

Select **Connect**. Artemis opens TUM.Live, where a TUM.Live course administrator selects a course and approves the request. The approver does not need an Artemis account. After approval, return to the TUM.Live page in Artemis and refresh the status.

The page shows the connected TUM.Live course, its visibility, and whether the saved grant is still active.

To remove access, select **Disconnect** and confirm. Artemis first revokes its exact grant in TUM.Live. If TUM.Live is temporarily unavailable, the saved connection remains visible so you can retry safely.

## Recordings of a connected course

When a lecture unit links a recording of the connected TUM.Live course, Artemis plays it in its own video player and can transcribe it for Iris, even if the TUM.Live course is not public. Students do not need a TUM.Live account for this; Artemis checks that they may see the unit. Lectures that are private in TUM.Live stay unavailable to Artemis.

The video address that Artemis gets is valid for seven hours. If a video stops playing after a page was open that long, reload the page.
