Every member of a course has a course role: **Student**, **Tutor**, **Editor** or **Instructor**. A user can hold several roles in the same course. Each role has its own members page, where you add users one by one or in bulk from a CSV file. See [Access Rights](/admin/access-rights) for the permissions of each role.

<Callout variant={CalloutVariant.info}>
Only instructors of the course and administrators can open the members pages.
</Callout>

## Opening User Management

Open the **Course Management** view and select your course. You can reach a members page in these ways:

- **Quick Actions**: Open the **User management** menu and select **Add student**, **Add tutor**, **Add editor** or **Add instructor**. The member counts next to the menu (**Students**, **Tutors**, **Editors**, **Instructors**) link to the same pages.
- **Direct URL**: Navigate to `/course-management/<course-id>/members/<role>`, where `<role>` is one of `students`, `tutors`, `editors` or `instructors` (e.g. `/course-management/42/members/students`).

Each page lists the members with that role together with their profile picture, login, registration number, name and email address. You can search by login, name, email address or registration number, and sort by every column except the profile picture.

## Adding Users

1. Open the members page of the role you want to assign.
2. Click **Add Users**.
3. Enter a name, login, matriculation number or email address, and select one or more users from the results. Users who already have the role cannot be selected. **View Selected** shows your selection.
4. Click **Register**. The users receive the role and appear in the table.

To give the same user several roles (for example, a tutor who also takes the course as a student), repeat the steps on the other members pages.

Course role changes apply on subsequent requests without signing in again. Users can reload an already open page if its controls have not updated. See [Access Rights](/admin/access-rights#roles-overview).

<Callout variant={CalloutVariant.info}>
The user must already exist in Artemis. If they have never logged in, they need to be created first either through self-registration, single sign-on, or by an administrator. See [User Registration](/admin/user-registration) for details.
</Callout>

## Importing Multiple Users via CSV

To add many users at once, click **Import Users** on the members page of the role. A dialog opens where you can select a CSV file.

### CSV Format

The first row of the file must contain headers. Each subsequent row must contain a value for **at least one** of `login`, `registration number`, or `email` &mdash; this is what Artemis uses to look up the existing user account. Additional columns are optional.

| Column                | Accepted header names                                                  | Required |
|-----------------------|------------------------------------------------------------------------|----------|
| Login                 | `login`, `user`, `username`, `benutzer`, `benutzername`                | Yes\*    |
| Registration number   | `registrationnumber`, `matriculationnumber`, `matrikelnummer`, `number`| Yes\*    |
| Email                 | `email`, `e-mail`, `mail`                                              | Yes\*    |
| First name            | `firstname`, `firstnameofstudent`, `givenname`, `forename`, `vorname`  | No       |
| Last name             | `familyname`, `lastname`, `familynameofstudent`, `surname`, `nachname`, `familienname`, `name` | No |

\* At least one of *Login*, *Registration number*, or *Email* must be present in each row. Headers are case-insensitive and ignore spaces and underscores.

### Example

```csv
login,email,registrationnumber,firstname,lastname
user_1,,,Alice,Smith
,user_2@artemis.org,,Bob,Jones
,,11712345,Carol,Müller
```

After you select the CSV file, Artemis displays a preview of the users. Click **Import** to give them the role. The dialog reports how many users were imported and how many were not found. Click **Finish** to close it.

<Callout variant={CalloutVariant.warning}>
Registration numbers in spreadsheets are often interpreted as numbers, which strips leading zeros (e.g. `01234567` becomes `1234567`). Format the column as **text** in your spreadsheet application before exporting to CSV, otherwise lookups by registration number may fail.
</Callout>

<Callout variant={CalloutVariant.info}>
Users that cannot be matched to an existing Artemis account are reported under **Not found** at the end of the import. They are not created automatically. Verify their identifier (login, registration number, or email) and ensure they have an account before re-importing.
</Callout>

## Removing a User

On the members page of a role, click the remove button in the user's row and confirm with **Remove**. The user loses this role in the course. Their submissions, results and participations are preserved.

Removing one role does not affect the other roles of the user in the same course. For example, removing a user from the tutors does not remove them from the students.

## Exporting Members

To export the members of a role, open its members page and click **Export as CSV**. The file contains the name, username, email address and registration number of every user with that role.
