Set up and manage your Artemis courses, import content from existing courses, and export data. Only administrators can create courses. As an instructor, you can request a new course through the course request feature or ask your administrator directly. For course creation and configuration details, see the [admin course documentation](/admin/courses).

This one-minute trailer walks through requesting, configuring, importing and exporting a course:
