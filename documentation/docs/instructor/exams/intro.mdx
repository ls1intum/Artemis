Artemis includes an online exam mode that allows you to create, conduct, and assess exams directly in the platform.

<Image src={timeline} alt="Timeline of an Artemis Exam" size={ImageSize.large} caption="Timeline of an Artemis Online Exam" />

## Creation and Configuration

During the exam creation and configuration, you can create your exam and configure it to fit your needs. Add exercises with different variants, register students, generate [student exams](/instructor/exams/prepare-and-test#manage-student-exams) and conduct test runs. For more information see [Create and Configure Exam](/instructor/exams/create-an-exam#create-and-configure-exam).
