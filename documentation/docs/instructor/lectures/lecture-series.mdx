A lecture series creates several lectures at once without their contents, so you can scaffold a whole semester at the
start of it and tell students when each lecture takes place. The contents are added later, lecture by lecture.

Open the **Lectures** page of the course in the course management, click **Create Lecture**, and switch the creation
mode from **Single Lecture** to **Lecture Series**.

<Image src={lectureSeriesImage} alt={"Lecture series creation page with the initial lectures and the series end date"} caption={"Lecture Series Creation Page"} size={ImageSize.medium}></Image>

A series is defined by its initial lectures and an end date. Give at least one initial lecture a start and an end
time, then set the date the repetition should stop at; Artemis repeats those initial lectures weekly until it reaches
that date.

The example below shows the <span style={{ color: 'skyblue' }}>lectures</span> generated from two
<span style={{ color: 'lightgreen' }}>initial lectures</span> and an
<span style={{ color: 'lightcoral' }}>end date</span>.

<Image src={lectureSeriesInputVisualization} alt={"Two initial lectures repeated weekly up to the series end date"} size={ImageSize.medium}></Image>

As soon as the inputs are valid the generated lectures appear as cards. The edit icon on a card changes that
lecture's title and timing, and the delete icon removes it from the series, so a week with no lecture in it does not
have to be worked around in the dates.

<Image src={lectureCardsImage} alt={"Generated lecture cards, each with an edit and a delete icon"} size={ImageSize.medium}></Image>
