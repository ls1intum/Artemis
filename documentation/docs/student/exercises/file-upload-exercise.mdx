A file upload exercise asks you to hand in a file rather than to write something in Artemis: a scanned worksheet, a
PDF report, a photograph of a diagram you drew on paper. You do the work wherever you like and upload the result.

## Hand In Your File

Open the exercise from the course's exercise list once it is released, and **Start exercise**. The file chooser
appears with **Supported file extensions** beside it — your file has to have one of those extensions or Artemis
will refuse it.

**Choose File**, then **Submit**. Nothing is stored until you submit: picking a file on its own does not hand it
in.

<Image src={beforeSubmitting} alt="File upload exercise with the file chooser and the accepted extensions" size={ImageSize.large} caption="Before submitting" />

Once the file is in, the page names it and says when it arrived, and offers **Download file** — worth using,
because it is the only way to confirm that the file Artemis has is the one you meant to send.

<Image src={afterSubmitting} alt="File upload exercise after submitting, offering the uploaded file for download" size={ImageSize.large} caption="After submitting" />

<Callout variant={CalloutVariant.warning}>

  You can replace your file by submitting again before the due date, and the newest submission is the one that gets
  marked. After the due date nothing more can be uploaded.

</Callout>

## Your Result

There is nothing to run against a file, so no result appears immediately. A tutor downloads your file, reads it and
writes feedback with points, and the result appears once the assessment is published — see
[Assessment](/student/exercises/intro) for what a published result looks like.
