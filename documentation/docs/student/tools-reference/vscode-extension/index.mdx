The Artemis extension for Visual Studio Code shows your courses, programming exercises and Iris inside the editor.
You can open an exercise, clone it, submit it and read the test results without switching to the browser, and ask
Iris about the code you are working on.

Only programming exercises are worked on in the editor. Text, modeling, quiz and file upload exercises appear in the
course lists too, but you complete them in Artemis in the browser.

## Where the Extension Runs

| Environment | How you get it | What differs |
|---|---|---|
| VS Code on your computer | Install **Artemis - TUM** from the VS Code Marketplace | Everything on these pages applies |
| VSCodium and other editors that use Open VSX | Install **Artemis - TUM** from Open VSX | No proactive help from Iris, no getting-started walkthrough |
| EduIDE in the browser | Already installed | You are signed in and your exercise is open when the workspace starts; no proactive help |

The extension needs VS Code 1.93 or newer and an Artemis server running version 9.9.0 or newer. On an older server it
still signs you in, but course contents do not load, and it says so in a warning after sign-in.

## Installing the Extension

1. Open the **Extensions** view in VS Code.
2. Search for **Artemis - TUM** and select **Install**.
3. Select the Artemis icon that appears in the activity bar on the left.

On a fresh installation VS Code also opens the walkthrough **Get Started with Artemis**. It covers choosing the
server, signing in, picking a folder for your exercises and opening Iris. These pages describe the same steps, so you
can close it if you prefer.

<Callout variant={CalloutVariant.info}>

  The extension adds two icons to the activity bar: **Artemis** for your courses and exercises, and **Iris Chat**
  for the tutor. The Iris Chat icon appears once you are signed in.

</Callout>
