## Overview

Artemis provides apps for Android and iOS/iPadOS. Use them to access your courses, read learning material,
and communicate with course members. The [feature comparison](#feature-comparison) explains the scope of each app,
including which activities require the web application.

Select your institution's Artemis server when signing in. The server must run a compatible Artemis version;
features also depend on your course's settings and your permissions. The apps use platform-specific interfaces,
so the same feature can look different on Android and iOS.

## Communication Features

Both apps support course channels, group conversations, and direct messages. Instructors can disable communication
or restrict a course to channels. Posting in an announcement channel, changing membership, moderating messages,
and managing channels require the corresponding permissions. These tables describe app support when the action is permitted.

| Feature | iOS | Android |
|---|---|---|
| Read and send messages; reply in threads | Yes | Yes |
| Edit your own messages and replies | Yes | Yes |
| Delete messages and replies when permitted | Yes | Yes |
| Add emoji reactions and see who reacted | Yes | Yes |
| Copy message text | Yes | Yes |
| Use Markdown formatting for bold, italic, underline, strikethrough, lists, quotes, and code | Yes | Yes |

| Mark an answer as resolving a question when permitted | Yes | Yes |

The development editor displays supported formatting while you type and lets you drag its handle to change its height.
Content that cannot be edited safely is preserved; this does not mean every Markdown construct is supported by the visual editor.
On iOS, a slide or lecture-unit reference opens the owning lecture rather than navigating to an exact PDF page.

## Android Application

### Installing the Android App

Install the Android app from [Google Play](https://play.google.com/store/apps/details?id=de.tum.cit.aet.artemis).

### Choosing a Server on Android

Select your institution from the server list, or choose **Custom instance** and enter the same Artemis URL that
you use in your browser. The unrestricted app offers TUM, KIT, and codeAbility as presets. Builds restricted to a
single institution can omit server switching.

<Image src={serverSelectionOverviewAndroid} alt="Android server selection" size={ImageSize.small} />

For a custom server, enter its URL in **Your instance url**, then select **Set custom instance** once the app
can reach the server.

<Image src={customServerEnteredAndroid} alt="Enter a custom Artemis server on Android" size={ImageSize.small} />

### Push Notifications on Android

During the initial notification setup for a server, use **Receive push notifications on this device?** to opt in
or out, then select **Continue**. Allow notifications in Android's permission prompt if you want to receive them.

<Image src={initialLoginNotificationAndroid} alt="Android push notification setup" size={ImageSize.small} />

Later, open the app's **Settings**, then **Notifications**, to change the device preference. In a course, the bell
opens notification presets and individual push notification types; it does not open a notification inbox.

<Image src={settingsPushAndroid} alt="Android device push notification setting" size={ImageSize.small} />

### Reporting an Android Problem

Please report any issues on the <a href="https://github.com/ls1intum/artemis-android/issues">GitHub repository</a>.

## iOS Application

### Installing the iOS App

The iOS application is available in the <a href="https://apps.apple.com/de/app/artemis-learning/id6478965616">App Store</a>.
To test the beta version, install Apple's TestFlight app and follow the link <a href="https://testflight.apple.com/join/canwoVCk">TestFlight</a>.

### Choosing a Server on iOS

Tap **Select university** on the sign-in screen. The list offers TUM, KIT, codeAbility, and Hochschule München,
followed by **Custom Instance**. For a custom server, enter the URL you use in your browser in
**Your custom Artemis instance URL**, then tap **Select**. The app checks that the URL points to an Artemis server.

<Image src={customServerEnteredIos} alt="Enter a custom Artemis server on iOS" size={ImageSize.small} />

### Push Notifications on iOS

After signing in, the app asks **Receive push notifications on this device?** if notification setup is still
needed. Choose **Register** or **Skip**, and allow notifications in the iOS permission prompt if you want to receive them.

To change a course's push notification preferences, open the course, tap the **Notifications** bell, then the
**Settings** gear to open **Notification Settings**. Choose a preset or change the individual notification types.
Use iOS Settings to enable or disable notification permission for the app.

## Force Update Mechanism

The native apps support a force-update mechanism to ensure compatibility and security, especially when breaking changes are introduced.

The Artemis server provides two configurable version thresholds:

- `min` – the **minimum required version**. Users must update the app before continuing.
- `recommended` – the **recommended version**. Users are prompted to update, but can continue using the app.
