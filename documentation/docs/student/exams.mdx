## Before You Start

Check the date, start time, and any registration requirements in your instructor's exam instructions. Before exam
day, make sure you can sign in to the Artemis instance your institution uses and open the course. Use an up-to-date
browser and check that your device can connect to the network you will use during the exam.

Check which tools and resources your instructor permits, including AI assistants built into editors. Disable any
features that the exam rules prohibit.

For programming exercises, check whether you will use the browser editor, a local editor, or either. If you will work
locally, install the required toolchain and Git client in advance. Set up repository access and test that you can
clone and push a practice repository. See [Integrated Code Lifecycle](/student/tools-reference/integrated-code-lifecycle).

If your course offers a practice exam, look for it under **Practice Exams** on the **Exams** page. Use it to try the
exam workflow, including submitting an exercise and handing in the whole attempt.

## What Happens If Your Connection Drops

Keep the exam tab open. You can continue working on text, quiz and modeling answers during a short outage. Artemis
retries saving them when the connection returns. Check the exercise status in the sidebar or **Overview** to make
sure your answers reached Artemis.

You can keep editing and committing code locally during an outage. You need a connection to clone or push a
repository, submit from the browser editor, or upload a file. If you cannot reconnect or save your work, contact the
exam supervisor promptly using the method your instructor provided.

<Callout variant={CalloutVariant.danger}>

  You need a connection to [hand in the exam](/student/exams/take-an-exam#hand-in) before the submission deadline.

</Callout>

## Two Rules Worth Following

**Keep the exam open in one browser tab.** Working in several tabs, windows or devices can make changes overwrite
each other.

**Reload only if you cannot recover otherwise.** For example, if the timer still looks wrong after checking your
connection and exam notifications, save your work and check its status before reloading. Unsaved changes can be
lost. If the welcome screen reappears, confirm the rules and enter your name again. Check your answers after you
return to the exam.
