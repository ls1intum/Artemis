# Client Guidelines

Artemis uses Angular, PrimeNG components, and Tailwind CSS. Follow the default path for new UI.
Use the TUM UI documentation when maintaining code that already imports `@tumaet/ui-angular` or
when an agreed cross-application requirement belongs in the package.
