# Client Guidelines

Artemis is migrating to its in-house TUM UI design system, with Tailwind CSS for application layout.
Bootstrap, ng-bootstrap, and PrimeNG are transitional dependencies rather than targets for new
component design.

Start with [Client Development](/developer/guidelines/client-development) for the component decision
path. Use the [TUM UI component reference](/developer/tum-ui-reference) to find supported components
and the [TUM UI package guide](/developer/guidelines/tum-ui-kit) when changing a reusable contract.
