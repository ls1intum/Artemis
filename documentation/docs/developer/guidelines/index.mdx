# Coding and Design Guidelines

Welcome to the Artemis Coding and Design Guidelines. These guidelines help maintain code quality, consistency, and best practices across the project.

<Callout variant={CalloutVariant.warning}>
**UI/UX Guidelines**

For all UI-related development work, you must follow the **[AET UI/UX Guidelines](https://ls1intum.github.io/ui-ux-guidelines/docs/intro)**. These external guidelines cover design principles (simplicity, consistency, feedback, accessibility, learnability), general conventions, accessibility standards, and component styling (buttons, headings, spacing, colors).

The Artemis-specific guidelines below focus on **implementation details** for Angular/TypeScript development, while the AET UI/UX Guidelines define the **design standards** you must follow.

</Callout>
